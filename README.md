# C++ Engineering Fundamentals (回路とC++の基礎)

A collection of Year 1 Electrical & Electronics Engineering console tools and C++ practice programs built on mobile.

## Projects
- **`circuit_calculator.cpp`** — Interactive console calculator for Ohm's Law ($V = I \cdot R$) and series/parallel equivalent resistance ($R_{\text{total}}$).

## Key Engineering Vocabulary (技術用語)
- **電圧 (でんあつ / *den'atsu*)** — Voltage
- **電流 (でんりゅう / *denryuu*)** — Current
- **抵抗 (ていこう / *teikou*)** — Resistance
- **回路 (かいろ / *kairo*)** — Circuit
